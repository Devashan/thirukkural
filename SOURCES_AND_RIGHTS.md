# Sources, attribution and rights

**Status:** source plan, not a rights declaration for an unpublished dataset. Every future data release must carry a field-level manifest naming the exact text source, edition, revision or scan, retrieval date, raw checksum, transformations and rights basis. Do not apply one blanket licence to every text in a mixed release.

Project Madurai, `tk120404/thirukkural`, `tshrinivasan/libkural` and other editions can be comparison witnesses. They are not automatic sources for shipped text or romanisation. In particular, do not copy encumbered commentary/translation fields or unexplained third-party transliterations into a release. If a future release actually derives protectable material from a separately licensed compilation, assess and comply with that compilation's terms.

Relevant source: [Srinivasan Wikisource edition](https://ta.wikisource.org/wiki/திருக்குறள்,_மூலம்). Exact English edition pinning remains to be completed before any populated release.

**No corpus-wide licence is declared yet.** This file is a planning record. Before publishing populated files, add a clear rights notice and licence text covering only rights that the project or its contributors can grant, with separate source attributions for other content.
